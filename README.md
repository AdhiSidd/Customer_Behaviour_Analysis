# Customer Shopping Analysis

## Project Overview

This project analyzes customer shopping data to understand customer behavior, purchasing patterns, sales performance, and product preferences.

The project follows an end-to-end data analytics workflow, starting with data cleaning and exploratory analysis in Python, followed by SQL analysis in MotherDuck, and finally creating an interactive Power BI dashboard.

## Dataset

The dataset contains customer shopping information such as:

- Customer ID
- Age
- Gender
- Item Purchased
- Category
- Purchase Amount
- Location
- Size
- Color
- Season
- Review Rating
- Subscription Status
- Payment Method
- Shipping Type
- Discount Applied
- Previous Purchases

## Tools & Technologies

- **Python** – Data cleaning and exploratory data analysis
- **Jupyter Notebook** – Python development and analysis
- **Pandas** – Data manipulation and cleaning
- **SQL** – Data querying and analysis
- **MotherDuck** – Cloud database for storing and querying the data
- **Power BI** – Data visualization and dashboard development
- **Power Query** – Data transformation
- **DAX** – Creating measures and calculations

## Project Steps

1. Loaded the raw customer shopping dataset into Jupyter Notebook.
2. Performed exploratory data analysis (EDA) using Python and Pandas.
3. Cleaned and prepared the dataset for analysis.
4. Loaded the cleaned data into MotherDuck.
5. Used SQL queries to explore customer and purchasing patterns.
6. Connected MotherDuck to Power BI.
7. Transformed and modeled the data in Power BI.
8. Created measures and KPIs.
9. Built an interactive customer shopping dashboard.
10. Analyzed the results to identify useful customer and sales insights.

## Dashboard

The Power BI dashboard provides insights into:

- Total customers
- Total sales
- Customer distribution by age group
- Sales by age group
- Sales by product category
- Customer gender distribution
- Subscription status
- Popular product sizes
- Customer purchasing behavior
